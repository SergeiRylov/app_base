# app_base

**app_base** — pip-пакет, реализующий базовый функционал и шаблоны для сайта на Django с использованием bootstrap5 admin template AdminLTE4 (https://adminlte.io/)

## Функционал

- Базовый шаблон страницы с подключением необходимых css и js
- Шаблоны для формирования полей форм
- Функционал для работы с модальными окнами
